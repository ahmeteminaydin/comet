Rate vs zenith angle

      
Simulated coincidence rate for 10 × 10 cm slabs 15 cm apart. Set an angle, simulate a run, and the points build up like a real angle sweep. Each point is the measured rate minus the accidental coincidence rate. The solid curve is the Monte Carlo estimate for this geometry; the dashed one is pure cos²θ scaled to the 0° rate.

      

    

    

      
      
    

    
θLive timeCountsMeasured /minAccidentalsCorrected /minExpectedCorr. / exp.

    
Corrected = measured − accidentals, with accidentals = (w_A + w_B) · R_A · R_B from the singles of each run. Here 100 ns × 40 Hz × 40 Hz ≈ 0.010 /min, so the correction is tiny unless the singles rates rise.

  


  

    
Probe points

    
What a scope would show at each test point for the last event. Time axis 0–200 ns. A noise hit fires channel A alone, so the coincidence gate stays low and no event record is written. Tilting the telescope changes how often events arrive, not the pulse shapes: accepted muons always cross both slabs nearly head-on.

    

  


  

    

      
Data stream

      
The serial lines the MCU sends to the PC logger. One EVT line per coincidence, a STAT line with hardware singles counts.
