# COMET System Schematic

Interactive system schematic for **COMET** (Compact Photonics-Enabled Cosmic Muon Detector), the BAATCH team's METU EE493–494 senior design project.

The page shows the whole detector on one sheet: muon, scintillator modules, SiPMs, bias supply and temperature compensation, analog front-end, comparators, pulse stretchers, coincidence logic, microcontroller, USB link, PC logger and GUI. Click any block to zoom into its detail sheet and open its build guide.

Everything is in `index.html` (no build step). Signals and count rates on the page are simulated. Part numbers and component values are a proposed baseline design, not a final bill of materials.
